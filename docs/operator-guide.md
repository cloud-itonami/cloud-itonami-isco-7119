# Operator Guide

## First Deployment

1. Define the operator's job-site scope and crew-intake process.
2. Register the job site and every crew that will be scheduled onto it.
3. Run synthetic scheduling/logistics cases.
4. Enable human-reviewed sign-off for `:high`/`:safety-critical`
   actions (every safety flag, every over-ceiling supply order).
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- consent and disclosure log
- safety-critical escalation path — every surfaced safety concern
  reaches a human, never auto-dismissed
- provenance for all operating records
- human review for high-risk cases (safety flags, over-ceiling supply
  orders)
- audit export for all gated actions

## Scope boundary

Operators must confirm this actor never performs framing work
itself, never finalizes a structural-framing-execution decision and
never overrides a site-safety officer's judgment. It coordinates
scheduling and logistics only.

## Certification

Certified operators must prove that the governor gates every
safety-critical robot action, that safety-critical risks escalate to
humans, and that no proposal can finalize a structural-framing-
execution decision or override a site-safety officer's judgment.
